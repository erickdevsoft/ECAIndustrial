# ECA Industrial

ECA Industrial is a fictional industrial software platform designed to simulate
and manage a modern manufacturing environment.

The project combines HMI, SCADA, MES and industrial simulation capabilities
using modern .NET and web technologies.

## Main Components

- ECA HMI — WPF + MVVM
- ECA SCADA — Angular + TypeScript
- ECA MES — Angular + TypeScript
- ECA API — ASP.NET Core
- ECA Simulator — .NET Worker Service

## Architecture

The platform follows Clean Architecture and Domain-Driven Design principles.
